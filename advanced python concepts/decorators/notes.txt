## 1. What is a decorator?

decorator is a function that takes a function and creates a new funciton and returnes that funciton ---

A **decorator is a function that takes another function, adds or modifies its behavior, and returns a function.**

For example, you can use decorators to:

* Execute code before or after a function.
* Handle exceptions in a reusable way.
* Repeat a function's execution.
* Measure execution time.
* Modify a function's output.

### Basic example

```python
def decorator(func):
    def wrapper():
        print("Before function execution")
        func()
        print("After function execution")
    return wrapper

def greet():
    print("Hello!")

greet = decorator(greet)
greet()
```

Output:

```text
Before function execution
Hello!
After function execution
```

**How does it work?**

1. `decorator(greet)` passes the `greet` function as an argument.
2. `wrapper()` adds behavior before and after calling `greet()`.
3. `return wrapper` returns the modified function.
4. `greet()` now executes the wrapper instead of directly executing the original function.

Python provides shorter syntax for this:

```python
@decorator
def greet():
    print("Hello!")
```

This is equivalent to:

```python
def greet():
    print("Hello!")

greet = decorator(greet)
```

## 2. Understanding your repeat decorator

Your idea is correct! You want a decorator that repeats a function `n` times.

Here's the implementation:

```python
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for i in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator


@repeat(3)
def greet(name):
    print(f"Hello, {name}!")


greet("Aditya")
```

Output:

```text
Hello, Aditya!
Hello, Aditya!
Hello, Aditya!
```

### Let's understand the three layers.

**Layer 1: `repeat(n)`**

```python
def repeat(n):
```

Accepts the number of repetitions.

Here, `n = 3`.

**Layer 2: `decorator(func)`**

```python
def decorator(func):
```

Accepts the function you want to decorate.

**Layer 3: `wrapper(*args, **kwargs)`**

```python
def wrapper(*args, **kwargs):
```

Executes the original function repeatedly.

* `*args` accepts positional arguments.
* `**kwargs` accepts keyword arguments.

For example, both of these calls work:

```python
greet("Aditya")
greet(name="Aditya")
```

Your decorator supports both because it forwards the arguments to the original function.

### Why do we need three functions?

Because we want to pass **both a repetition count and a function**.

The structure is:

`repeat(n)` → receives the repetition count.

`decorator(func)` → receives the function.

`wrapper(*args, **kwargs)` → executes the function.

This pattern is called a **decorator with arguments**.

## 3. One important detail

Consider this code:

```python
def wrapper(*args, **kwargs):
    for i in range(n):
        func(*args, **kwargs)
```

This repeats the function, but it doesn't return the function's result.

If you want the wrapper to preserve the original function's return value, you need to decide how to handle repeated results.

For example, to return the result of the final execution:

```python
def wrapper(*args, **kwargs):
    result = None
    for i in range(n):
        result = func(*args, **kwargs)
    return result
```

Now, if the decorated function returns a value, the wrapper returns the final result.

**Remember:** A decorator doesn't necessarily have to modify a function's output. It can also add behavior around the function's execution.

## 1. Why do we need decorators?

Imagine you have 20 functions in your application, and you want to measure how long each takes to execute.

Without decorators, you'd need to modify every function.

With decorators, you write the timing logic once and reuse it wherever needed.

**That's the main purpose: reusable behavior without repeatedly modifying the original functions.**

## 2. Four practical use cases

### ① Measuring execution time

Useful when optimizing Python code and ML pipelines.

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Time taken: {time.time() - start:.4f} seconds")
        return result
    return wrapper

@timer
def process_data():
    time.sleep(2)

process_data()
```

Now, any function decorated with `@timer` automatically reports its execution time.

### ② Authentication and access control

Suppose you're building an AI application with a function that deletes documents.

You want to ensure only authorized users can execute it.

A decorator can check permissions before allowing the function to run.

Frameworks such as FastAPI also provide dependency-based approaches for authentication and authorization; decorators are one possible way to organize access-control behavior.

### ③ Exception handling and logging

Suppose your application has multiple functions that call a database or an AI model.

You want to log errors consistently instead of writing the same logging code inside every function.

A decorator can centralize that behavior.

```python
def handle_errors(func):
    def wrapper(*args, **kwargs):
        try:
            return func(*args, **kwargs)
        except Exception as e:
            print(f"Error occurred: {e}")
    return wrapper

@handle_errors
def divide(a, b):
    return a / b

divide(10, 0)
```

Output:

```text
Error occurred: division by zero
```

**Note:** This example demonstrates the concept. In production, you would generally use proper logging and decide which exceptions should be caught rather than swallowing every exception.

### ④ Web development and AI APIs

When you eventually build AI applications using FastAPI, you'll encounter decorators frequently.

For example:

```python
@app.get("/predict")
def predict():
    return {"prediction": "positive"}
```

Here, `@app.get("/predict")` registers the function as a handler for HTTP GET requests to `/predict`.

You don't need to implement this decorator yourself. The framework provides it.
